# TouringHub Map Behavior

更新日: 2026-10-01

地図操作、レイヤー表示、ポップアップ、モバイルジェスチャの仕様をまとめます。

## 1. 地図初期表示

- ライブラリ: Leaflet 1.9.4
- タイル: OpenStreetMap
- 初期中心: `[35.6895, 139.6917]`
- 初期ズーム: `11`
- Leaflet設定: `{ tap: false, doubleClickZoom: true }`

## 2. 地図上のUI

- 左上寄り: Zoomバッジ
- 右上: 操作ガイド、座標移動パネル
- 右下: 現在地ボタン、全画面ボタン
- 下部中央: 地図データ読み込み状態
- PC幅: 凡例は地図左下に重ねて表示
- モバイル幅: 凡例は地図下の通常フローで表示

## 3. 現在地

- `navigator.geolocation.watchPosition()` で現在地を監視します。
- 初回取得時に現在地マーカーを作成します。
- 以降はマーカー位置を更新します。
- 現在地ボタン押下時、現在地マーカーがある場合のみズーム14で移動します。

## 4. 仮ピン

### PC

- 地図上で右クリックすると仮ピンを設置します。

### モバイル

- 1本指の長押し800msで仮ピンを設置します。
- `touchend`、`dblclick`、`touchmove` で長押しタイマーを解除します。

### 表示

- 仮ピンは1つだけです。
- 既に存在する場合は位置を更新します。
- ポップアップ名は `指定した地点` です。

## 5. 座標移動

- 入力形式は `緯度,経度` です。
- 緯度範囲は -90 から 90 です。
- 経度範囲は -180 から 180 です。
- 移動時はズーム16で `map.setView()` します。
- 移動先に仮ピンを設置します。

## 6. ポップアップ

共通ポップアップには以下を表示します。

- 名称
- カテゴリ
- 説明文
- Googleマップで開く
- ルート検索（高速）
- ルート検索（下道）
- 緯度・経度をコピー

`名道` のポップアップでは、既定で緯度経度コピーを表示しません。

## 7. レイヤー

### uMap由来

- `umap_backup_map.umap` の `layers` を読み込みます。
- Point はマーカーまたはアイコンで表示します。
- LineString は線と透明なクリック領域を重ねて表示します。

### 道の駅

- `P35-18_Roadside_Station.geojson` を読み込みます。
- `道の駅` レイヤーとしてクラスタ付き表示します。

### 高速道路IC

- 専用アイコン `images/ic_logo.png` で表示します。
- PCはズーム11以上、モバイルはズーム10以上で表示します。
- 凡例には表示しません。

## 8. クラスタリング

- Point系レイヤーは原則 `L.markerClusterGroup()` を使います。
- `disableClusteringAtZoom` は 10 です。
- クラスタアイコンはレイヤー色の丸バッジです。
- 高速道路ICはクラスタリングしません。

## 9. 凡例

- レイヤーごとにチェックボックスを生成します。
- チェックONで `map.addLayer(layerGroups[name])`。
- チェックOFFで `map.removeLayer(layerGroups[name])`。
- 凡例IDは `legend-item-レイヤー名` です。
- 高速道路ICは `showInLegend: false` です。

## 10. モバイルジェスチャ

### 判定条件

`isMobileMapView()` は以下のいずれかでモバイル/タッチ扱いにします。

- `max-width: 767px`
- `pointer: coarse`
- `ontouchstart in window`
- `navigator.maxTouchPoints > 0`

### ダブルタップ判定

- 前回タップから350ms以内
- 前回タップ位置から40px以内

### ダブルタップズーム

- 2回目タップ後、指を動かさず離すと1段階ズームインします。

### 片指ズーム

- 2回目タップ後、指を触れたまま上下に動かします。
- 10px以上動くと移動ありとして扱います。
- 70pxごとにズーム段階を変更します。
- 下方向でズームイン、上方向でズームアウトします。
- 片指ズーム中はLeaflet標準ドラッグを一時停止します。
- `touchend` または `touchcancel` で、片指ズーム開始前のドラッグ有効状態へ戻します。

## 11. 変更時の注意

- 長押しピン、ダブルタップズーム、片指ズームは同じタッチイベント群を使うため、変更時は相互干渉を確認してください。
- `preventDefault()` と `stopPropagation()` の位置を変えるとLeaflet標準操作へ影響する可能性があります。
- レイヤー名、凡例ID、`layerGroups` のキーは実質的な結合点です。
- 初期中心/初期ズームは不用意に変更しないでください。

## 12. 段階生成と読み込み状態

- uMapと道の駅を含む全レイヤーは、現在の表示範囲を1.4倍した先読み範囲に含まれる未生成Featureだけを生成します。
- 初期表示範囲はデータ読み込み後に即時生成します。
- 地図移動後は、移動終了から1.5秒間動かなかった場合に生成を開始します。
- 1.5秒以内に移動を再開した場合は待機タイマーをリセットします。
- 実行中に移動を開始した場合は世代番号を更新し、以降のチャンク生成を中断します。
- 一度生成したFeatureは地図移動後も削除せず、同じFeatureを再生成しません。
- 対象Featureは40件単位で生成します。
- チャンク間は `requestIdleCallback()` を使用し、非対応環境では `setTimeout(..., 0)` を使用します。
- 生成優先度は以下です。
  1. 名道、景勝地、グルメ
  2. その他（道の駅を含む）
  3. 高速道路IC
- 同一優先度のレイヤーは、1レイヤーを全件完了させてから次へ進むのではなく、チャンク単位で交互に生成します。
- 凡例とレイヤーグループは従来のデータ順で先に準備し、Featureの生成順だけを優先度制御します。
- 読み込み中は現在の生成対象に対する完了Feature数と総Feature数を表示します。
- 対象範囲の生成完了時は完了メッセージを表示した後、自動的に非表示にします。
- 一部データの読み込みに失敗した場合は、エラーメッセージを表示し続けます。

## 13. 画面ONモード（2026-10-01追加）

- 767px以下かつ地図全画面時だけ、既存ボタン列の下に「画面 OFF/ON」を表示します。
- `navigator.wakeLock.request('screen')` が成功した場合だけ設定をONにします。非対応・取得失敗時はOFFに戻します。
- ユーザー設定とWake Lock Sentinel、取得中リクエスト、スマホ幅、地図全画面、ページvisibleを分離して管理します。
- 実際にWake Lockを保持している間だけ、上部中央に「画面ONモードが有効です。画面の点灯を維持します。」を表示します。
- 非表示・OSによるreleaseでは設定を維持してステータスを隠します。自動release直後には再取得せず、visibleへの復帰時に設定ON・スマホ幅・地図全画面なら再取得します。
- OFF操作、全画面解除、PC幅への切り替えでは明示releaseし、設定もOFFにします。全画面再開時は自動ONにしません。
- 取得中にOFF・全画面解除・非表示となった場合、遅れて成功したSentinelもreleaseします。
- 手動消灯・画面ロックはブラウザ/OSに従います。APIキー・外部依存の追加はありません。

## 14. 雨雲（2026-10-01追加）

- PC/スマホの通常・全画面で「☔ 雨雲」ボタンを表示します。通常表示とPC全画面は現在地ボタンの上、スマホ全画面は画面ONボタンの下です。高さ500px以下・幅568〜767pxの通常表示では追従ボタンの隣へ配置します。初期状態はOFFです。
- ONで半透明の降水タイル（不透明度0.55）を追加し、下部に「現在 / +10 / +20 / +30 / +40 / +50 / +60分」、実際の表示時刻（日本時間）、気象庁への出典リンク、「雨雲更新：HH:mm」を表示します。更新時刻は正常取得したデータの取得時刻（日本時間）で、更新の反映失敗時には進めません。
- 「現在」はN1の最新実況です。予測は最新実況のvalidtimeに指定分数を加え、N2の最新basetime系列から最も近いvalidtimeを選びます。端末時計は時刻選択に使いません。対応時刻の差が5分を超える場合は取得失敗として扱います。
- 気象庁公式設定に従いタイルのネイティブズームは4/6/8/10で、他の地図ズームでは拡大縮小します。既存の地図ズーム上限は維持します。
- OFFで雨雲レイヤーと時間UIを解除します。通常表示⇔全画面やPC/スマホ幅の切替ではON/OFFと選択中の予測時刻を維持します。地図の中心・ズーム・追従・現在地・既存レイヤーには触れません。
- 時間UIはPCで凡例と右側ボタン列の間、スマホ全画面で下部中央に表示します。
- スマホ通常表示（767px以下・非全画面）では、地図直下に高さ約72pxのバー「‹ 現在 HH:mm ›」または「‹ +30分 HH:mm ›」を常駐表示し、その下に出典と最終更新時刻を小さく表示します。左右で全7時刻を順送りし、端のボタンは無効にして循環しません。
- 中央タップ時だけバーの上に既存の全時刻ボタンを小型ポップアップで表示し、選択後に自動で閉じます。中央の再タップ、Escape、雨雲OFF、画面種別切替でも閉じます。通常⇔全画面、PC⇔スマホ幅の切替で選択時刻と雨雲状態を維持します。
- JSONは5分のメモリキャッシュを共有し、手動操作時に鮮度を判定して同時取得をまとめます。自動通信は画面ON設定＋雨雲ON＋ページvisibleの間だけ10分ごとに最新JSONを取得します。タイマーは最大1つです。いずれかOFF、非表示、pagehideでは停止し、進行中の自動取得/置換も中断します。
- visibilitychange/pageshowで復帰した際、画面ON設定＋雨雲ONで前回の正常JSON取得から5分以上経過していれば直ちに再取得します。5分未満は再取得せず10分タイマーを再開します。
- 自動更新は選択中の相対分数を維持します。「現在」は新しい実況へ、「+30分」等は新しい実況基準の同じ分数の予測へ切り替えます。地図中心・ズーム・追従・マーカー・ルート・全画面・画面ONを変更しません。
- 自動更新では新タイルの読み込み成功まで旧雨雲を維持します。JSON/タイルの失敗・タイムアウトでは旧雨雲と更新成功時刻を維持し、「雨雲情報を更新できませんでした」を5秒表示して次の10分更新で再試行します。
- JSON取得は10秒、タイル読み込みは15秒でタイムアウトします。初回/手動操作の通信失敗・無効な時刻データ・現在レイヤーのtileerrorでは従来どおり雨雲だけをOFFにし、「雨雲情報を取得できませんでした」を5秒表示します。次のONで再取得できます。
- アニメーション、ルート判定、独自予測、通知は追加していません。
