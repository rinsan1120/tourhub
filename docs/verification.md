# TouringHub Verification Guide

更新日: 2026-06-11

変更後の確認観点をまとめます。

## 1. 基本方針

- ローカル確認はHTTPサーバー経由で行います。
- `index.html` の直接オープンでは `fetch()` が失敗する可能性があります。
- 変更範囲に応じて、地図、天気、設定txt、UI表示を確認します。

## 2. ローカル起動

```powershell
python -m http.server 8000
```

ブラウザで開くURL:

```text
http://localhost:8000/
```

## 3. 共通確認

- ページが表示されること。
- ブラウザコンソールに重大なエラーがないこと。
- 外部CDNの読み込みに失敗していないこと。
- GitHub Pages前提の相対パスが壊れていないこと。
- PC幅とスマホ幅で大きな表示崩れがないこと。

## 4. JavaScript変更時

- 可能なら対象JSに対して構文チェックを行います。

```powershell
node --check conf\map-engine.js
node --check conf\weather-engine.js
node --check conf\michi-no-eki.js
```

- ブラウザで該当機能を実操作します。
- 非同期読み込みの失敗時表示も確認します。

## 5. 地図変更時

確認項目:

- 地図が表示される。
- 初期中心と初期ズームが意図せず変わっていない。
- OSMタイルが表示される。
- uMap由来レイヤーが表示される。
- 道の駅が表示される。
- 高速道路ICがズーム条件どおり表示される。
- 凡例チェックで表示/非表示が切り替わる。
- Pointポップアップが開く。
- 名道ポップアップが開く。
- Googleマップリンクが開く。
- 高速/下道ルート検索リンクが開く。
- 緯度経度コピーが動作する。
- 右クリックまたは長押しで仮ピンが置ける。
- 現在地ボタンがエラーなく動作する。
- 全画面ボタンが動作する。
- 座標移動が動作する。
- 読み込み中に進捗表示が出る。
- 表示範囲のデータ生成後に完了表示が出て、自動的に消える。
- データ読み込み失敗時にエラー表示が残る。
- 段階生成中も地図のパンやページスクロールが完全には停止しない。

### 表示範囲連動生成

- 初期表示範囲はデータ読み込み後に即時生成される。
- 初期表示時に表示範囲外のPointが生成されない。
- 先読み範囲が表示範囲の1.4倍である。
- 地図移動終了から1.5秒未満では新しいFeatureが生成されない。
- 地図移動終了から1.5秒以上停止すると、新しい範囲のFeatureが生成される。
- 待機中に移動を再開すると、古い待機タイマーが実行されない。
- 段階生成中に移動を開始すると、古い世代の後続チャンクが生成されない。
- 移動前に生成済みのFeatureが移動後も削除されない。
- 同じ範囲へ戻っても生成済みFeatureが重複生成されない。
- 高速道路ICは表示ズーム条件を満たす場合だけ生成される。

### 段階生成順

- 名道、景勝地、グルメが優先度1として生成される。
- 優先度1の3レイヤーがチャンク単位で交互に生成される。
- その他レイヤー（道の駅を含む）は優先度1の完了後に生成される。
- 高速道路ICは最後に生成される。
- 凡例の表示順は従来どおりである。
- 段階生成中に凡例をOFFにしても、生成完了後に意図せずONへ戻らない。

## 6. モバイル地図操作変更時

確認項目:

- 通常のパンができる。
- ピンチズームが壊れていない。
- 長押しで仮ピンが置ける。
- 単純なダブルタップでズームインする。
- 2回目タップ保持から下方向移動でズームインする。
- 2回目タップ保持から上方向移動でズームアウトする。
- 操作ガイドや座標移動UIがタッチ操作を妨げない。

## 7. 天気変更時

確認項目:

- 天気カードを展開できる。
- 最初のエリアが表示される。
- 最初のエリアの天気が取得される。
- タブ切り替えで対象エリアが表示される。
- 未取得エリアの天気が取得される。
- 再取得ボタンが動作する。
- 地点名リンクがGoogle検索を開く。
- 地名で天気検索が新規タブを開く。

## 8. 設定txt変更時

### 共通

- UTF-8で保存されていること。
- `//` コメントで意図しない削除が起きていないこと。
- URL内の `://` が維持されること。

### `weather.txt`

- エリアタブが崩れない。
- 地点行が天気表に表示される。
- 緯度経度がOpen-Meteo APIに渡る。

### `nearby.txt`

- ボタンが表示される。
- Font Awesomeアイコンが表示される。
- Google Maps検索が開く。

### `link.txt`

- カテゴリが表示される。
- リンクカードが表示される。
- `<br>` を含むリンク名の表示が崩れない。

### `drawer-links.txt`

- ドロワー内カテゴリとリンクが表示される。
- 長いURLでもリンクとして開ける。

### `updates.txt`

- 新しい更新が上に表示される。
- `日付 | 内容` の分割が崩れない。

## 9. ドキュメント変更時

- PowerShellでは必ずUTF-8を指定して読む。

```powershell
Get-Content -Raw -Encoding UTF8 docs\<file>.md
```

- 実装と矛盾する記述がないか確認する。
- 推測と確定情報を混ぜない。

## 10. 確認できない場合の報告

以下を明記します。

- 実施できなかった確認
- 理由
- 代替確認
- 残るリスク
